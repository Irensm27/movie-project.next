## Сторінки

### Головна сторінка з фільмами

URL: `/movies`

Кореневий маршрут `/` перенаправляє користувача на `/movies`.

На сторінці розміщені:

- Header;
- інформація про користувача;
- пошук фільмів;
- сортування фільмів;
- банер із фільмами з високим рейтингом;
- список жанрів;
- список фільмів;
- картки фільмів із постерами, рейтингами та жанрами;
- пагінація.

Основні можливості:

- пошук фільмів за назвою або її частиною;
- сортування за популярністю, рейтингом і датою виходу;
- фільтрація фільмів за жанрами;
- одночасне використання пошуку, сортування та фільтрів за жанрами;
- перехід між сторінками списку фільмів;
- перехід до сторінки детальної інформації про вибраний фільм.

Параметри пошуку, сортування, жанру та сторінки передаються через URL. Це дозволяє зберігати поточний стан фільтрації під час навігації.

### Сторінка окремого фільму

URL: `/movies/[id]`

Приклад: `/movies/550`

На сторінці відображається детальна інформація про вибраний фільм:

- назва;
- фонове зображення;
- постер;
- рейтинг;
- жанри;
- дата виходу;
- кількість голосів;
- тривалість фільму;
- опис.

Кнопка Back to movies дозволяє повернутися до списку фільмів.

Для неіснуючого фільму передбачена сторінка Movie not found.

## Основний функціонал

У проєкті реалізовано:

- отримання списку фільмів із TMDB API;
- отримання списку жанрів;
- отримання фільмів із високим рейтингом для банера;
- пошук фільмів;
- сортування за популярністю, рейтингом і датою виходу;
- фільтрацію за жанрами;
- пагінацію списку фільмів;
- перегляд детальної інформації про фільм за його ID;
- обробку помилок завантаження та відображення стану завантаження;
- обробку ситуації, коли фільм не знайдено;
- повторне використання компонентів для відображення інформації про фільми.

## API

Для отримання інформації про фільми використовується The Movie Database (TMDB) API.

Base URL: `https://api.themoviedb.org/3`

У проєкті використовуються запити для отримання списку фільмів, пошуку, отримання жанрів, фільмів із високим рейтингом та детальної інформації про конкретний фільм.

Запити до API виконуються за допомогою серверних функцій `fetch`. Для кешування даних використовується механізм Next.js.

Дані про фільми надаються сервісом [The Movie Database (TMDB)](https://www.themoviedb.org/).
